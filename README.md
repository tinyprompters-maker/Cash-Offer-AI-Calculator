# Cash Offer AI Calculator

AI-assisted real estate cash-offer calculator prototype for quickly estimating offer ranges, repair assumptions, and deal viability.

## What It Includes

- Browser-based calculator UI
- Deal input fields for property and offer assumptions
- Gemini service integration scaffold
- Reusable numeric input component
- TypeScript types and constants for deal calculations

## Stack

- React
- TypeScript
- Vite
- Gemini API service scaffold

## Run Locally

```bash
npm install
npm run dev
```

Set `GEMINI_API_KEY` in `.env.local` if using the AI-assisted features.

## Portfolio Status

This is a prototype. Before using it as a public customer-facing tool, verify the assumptions, add clear disclaimers, and replace any demo-only calculations with validated underwriting logic.
